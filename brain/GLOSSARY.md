# GLOSSARY.md
| Term | Meaning |
|---|---|
| AC / PC | Assembly Constituency / Parliamentary Constituency |
| Booth / Polling Station (PS) | Smallest unit where votes are cast and counted; identified by part number within an AC |
| Part number | Electoral-roll section ID, usually the booth ID |
| Form 20 | Statutory return of booth-wise results per AC |
| EPIC | Elector Photo Identity Card number (sensitive; never stored) |
| CEO UP | Chief Electoral Officer, Uttar Pradesh |
| BLO | Booth Level Officer |
| TCPD / Lok Dhaba | Trivedi Centre for Political Data (Ashoka Univ.) / its election-data portal |
| SHRUG | Socioeconomic High-resolution Rural-Urban Geographic dataset (Development Data Lab) |
| Swing (pp) | Change in vote share between elections in percentage points |
| NOTA | None of the Above |
| Crosswalk | Mapping of booth identities across elections (handles splits/merges) |
| Voronoi cell | Region closer to one booth point than any other; approximates catchment |
| Residualization | Subtracting regional trend so only local deviation remains |
| EB shrinkage | Empirical-Bayes pull of noisy small-sample estimates toward the group mean |
| Isolation Forest | Unsupervised outlier detector based on random partitioning |
| Stance | Attitude toward a specific target (party/candidate/issue) |
| MCC | Model Code of Conduct |
| DPDP Act | Digital Personal Data Protection Act, 2023 |
| Modeled estimate | A value inferred statistically, not directly observed |
