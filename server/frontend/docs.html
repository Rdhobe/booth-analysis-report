UPBI API docs

read-only JSON for the Next.js frontend · base http://127.0.0.1:8000 · examples below are real responses from the full 403-AC store

Swagger

Next.js quickstart

const API = process.env.NEXT_PUBLIC_UPBI_API ?? "http://127.0.0.1:8000";
const KEY = process.env.UPBI_API_KEY; // server-side only — never NEXT_PUBLIC_
const meta = await (await fetch(`${API}/api/meta`,
  { headers: KEY ? { "x-api-key": KEY } : {} })).json();
const page = await (await fetch(`${API}/api/booths?ac=88&sort=latest_diff&order=desc&page=1`,
  { headers: KEY ? { "x-api-key": KEY } : {} })).json();

CORS: GET from any origin is allowed by default. Tighten with ALLOWED_ORIGINS="https://app.vercel.app" on public deploys. All responses are gzip-encoded JSON (orjson). Every endpoint opens its own read-only SQLite connection — safe to call in parallel.

Auth

RuleDetail
Headerx-api-key: <API_KEY> on every /api/* call. Missing/wrong → 401 {"detail": "invalid or missing API key"}.
Dev vs prodAPI_KEY unset = open mode (localhost convenience; server logs a warning). Any shared/public deploy must set it: API_KEY="…" (uvicorn env) or via render.yaml / fly.toml secrets.
Public pages/docs, /swagger, /openapi.json, /assets/*, and /api/meta (health checks) need no key — the data does. (The dashboard lives in the Next.js app, not here.)
Next.js guidanceCall this API from Route Handlers / Server Components so the key never reaches the browser. If the browser must call it directly, accept that the key is public and rely on ALLOWED_ORIGINS + (later) rate limits instead.

Conventions

RuleDetail
ElectionsVS2017 · LS2019 · VS2022 · LS2024
Value scalesshares/margins/turnout (a2017,b2017,d2017,avg_diff,latest_diff,to2017…) are fractions 0–1 → display ×100. Religion *_percent_17 are already 0–100. age_* are years. e/m/f/o/t are headcounts.
Nullsnull = suppressed (booths < 200 electors), no input, or not applicable — never 0. to* is null where electors are missing.
Sortingsort accepts any booth_row column name; unknown keys fall back to ps. order=asc|desc.
Scoping/api/booths requires ac=<no> or q=<text> (FTS prefix search over AC/PS/name/district) — never full-table. page_size ≤ 500, default 100.
source/api/ac/{ac}/votes returns "sum of converted booths", or "official ECI segment totals (all-AC)" when 2024 booth files are missing for that AC.
store_ok/api/meta.store_ok === false means the build was interrupted — rebuild before trusting any page.
Religion columns36 *_17 columns are modeled 2017-roll estimates (religion inferred from names; age/sex from the roll). Tag them (modeled) and link Methods — same rule as the dashboard.
CachingStatic endpoints (meta/acs/overview/trend/sexratio/religion/ages/averages/past/zones/coverage/methods) are cached in-memory server-side — repeats are instant. The store is immutable, so a rebuild needs a server restart to take effect.
Errors400 unscoped booths query · 401 bad/missing API key · 404 unknown booth · 500 store file missing (set DB_PATH).
