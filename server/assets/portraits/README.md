# portraits — candidate portraits

Served at `/assets/portraits/<file>`. JPG, portrait orientation,
~512px on the long edge. One file per candidate:

- filename = candidate name, lowercase, spaces → underscores,
  punctuation stripped. E.g. `PROF S P SINGH BAGHEL` →
  `prof_s_p_singh_baghel.jpg`
- missing file = no portrait shown (frontend hides the slot).

Source portraits only from openly licensed or campaign-published
photos; note the source next to any disputed image.
